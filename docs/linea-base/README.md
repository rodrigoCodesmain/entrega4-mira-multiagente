# Línea base con un solo agente

Guardar aquí el prompt, la referencia al commit inicial, las aclaraciones aplicables, los resultados y la evidencia de la ejecución con un solo agente. Usar la misma necesidad, versión inicial del proyecto y criterios de comprobación que en la corrida multiagente.

Registrar en la [bitácora](../bitacora.md) el tiempo, las interacciones, las correcciones, los resultados de las pruebas y los criterios cumplidos. Anotar los tokens o el costo cuando la herramienta los informe y marcar ese dato como no disponible cuando corresponda.
