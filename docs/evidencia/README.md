# Evidencia de la corrida multiagente

Guardar por identificador de corrida los prompts, capturas, logs, salida de pruebas y resultados reales. Los archivos de traspaso se conservan en [`docs/trabajo/`](../trabajo/). Enlazar cada evidencia desde la [bitácora](../bitacora.md) con el agente, el paso, la fecha y el commit correspondiente.

Cuando una falla se corrija, vincular la evidencia original, el cambio y el resultado de la nueva ejecución. Si el archivo es un log de pruebas, conservar el comando y el código de salida.
